# 🏥 Hospital Appointment System

A complete web-based Hospital Appointment Management System built using **Java Servlets**, **JDBC**, **MySQL**, and **HTML/CSS**. This project demonstrates all core database operations: **INSERT**, **UPDATE**, **DELETE**, **CREATE**, and **SELECT** via simple servlets.

---

## ✨ Features

- 📅 **Book an appointment** (INSERT operation) – patient registration + appointment scheduling  
- ✏️ **Cancel an appointment** (UPDATE operation) – change appointment status to 'CANCELLED'  
- 🗑️ **Delete a patient record** (DELETE operation) – removes patient and all linked appointments  
- 🆕 **Create a feedback table** (CREATE operation) – dynamically adds a new table to the database  
- 👁️ **View all appointments** (SELECT operation) – displays appointments with patient and doctor details  

- 🎨 **Responsive, modern UI** – gradient backgrounds, card layout, smooth hover effects  
- 🔐 **Simple servlet‑based architecture** – no complex frameworks, easy to understand and extend  

---

## 🛠️ Technologies Used

- **Backend**: Java Servlets (JDK 8/11/17), JDBC  
- **Frontend**: HTML5, CSS3, JavaScript  
- **Database**: MySQL  
- **Server**: Apache Tomcat 9  
- **Version Control**: Git & GitHub
